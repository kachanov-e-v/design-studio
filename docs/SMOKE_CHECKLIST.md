(протокол v9, 505 тестов / 37 файлов) подтверждено только jsdom/unit-тестами;

## Как прогонять

1. `npm install`, затем `npm run build` (и `npm test` — юнит-тесты должны быть зелёными).
2. Откройте папку расширения в VS Code и нажмите **F5** (Extension Development Host).
3. В хосте откройте demo-страницу (**Демо** в списке проекта) или папку Next.js-проекта
   с запущенным `npm run dev`; выполните **Дизайн-студия: Открыть дизайн-студию**.
4. Для проверок безопасности и регрессий откройте devtools вебвью:
   **Developer: Open Webview Developer Tools**; origin preview-хоста виден в `src` iframe
   (`http://127.0.0.1:<PORT>`). Ниже `<PORT>` — этот порт.
5. Отмечайте пункты `[x]`, failures записывайте в таблицу результатов в конце файла.

- [ ] RU/EN: переключатель языка меняет весь UI (тулбар, инспектор, попап, тосты); верните RU.

## 2. Режим «Просмотр»

- [ ] Ссылки и SPA-навигация: клик по внутренней ссылке меняет маршрут без перезагрузки iframe; адресная строка обновляется.
- [ ] Формы: ввод и submit работают штатно (на demo или странице логина проекта).
- [ ] Назад/вперёд: кнопки тулбара перемещают по истории предпросмотра.
- [ ] Перезагрузка: кнопка reload перезагружает страницу, состояние просмотра сохраняется.
- [ ] Адресная строка: ввод `/login` или полного `http://localhost:3000/login` + Enter открывает маршрут.

## 3. Режим «Редактировать»

- [ ] Сегментированный переключатель **Просмотр / Редактировать**: активный сегмент подсвечен, режим меняется по клику.
- [ ] Акцентная рамка: в режиме правки вокруг предпросмотра появляется фиолетовая рамка; в просмотре исчезает.
- [ ] Hover-подсветка: наведение рисует outline поверх элемента, точно по его границам.
- [ ] Клик выбирает, не активируя: клик по ссылке/кнопке в режиме правки выбирает элемент (инспектор заполняется), страница не реагирует.
- [ ] Попап выбора: появляется у элемента; при скролле страницы и resize окна остаётся привязанным к элементу, не уезжает за viewport.

## 4. Инспектор

- [ ] Секции: заголовки секций сворачивают/разворачивают содержимое по клику.
- [ ] Липкие заголовки: при скролле инспектора заголовок секции остаётся видимым сверху.
- [ ] Фильтр свойств: ввод (например, `color`) сужает список контролов; очистка возвращает все; по запросу без совпадений — «Нет свойств по запросу».
- [ ] Текст: правка текста коммитится по blur и по Enter; Escape отменяет ввод без изменений.
- [ ] Классы: чипы классов добавляются и удаляются, изменение видно на странице.
- [ ] Атрибуты: редакторы соответствуют тегу (`href` у `a`, `placeholder` у `input`, `checked`/`disabled` и т.д.); правка применяется к DOM.
- [ ] Стили: контролы unit/select/slider меняют CSS-свойства, значение видно на элементе.
- [ ] Box-model: правка margin/border/padding по сторонам пересобирается в корректный CSS-shorthand (проверьте computed style в devtools страницы).
- [ ] Цвет: пикер + альфа-слайдер применяют `rgba(...)` с ожидаемой альфой.
- [ ] Типографика: превью шрифта/размера/интервала отражает реальные значения выбранного элемента.

## 5. Журнал правок и отмена

- [ ] Чипы вида: каждая правка получает верный чип — стиль/текст/классы/атрибут/структура/комментарий; значения до/после корректны.
- [ ] Структурная отмена: переместите/удалите элемент, нажмите **Отменить структурную правку** — DOM восстанавливается из снапшота, запись исчезает из журнала.
- [ ] Отмена стиля/текста/класса/атрибута: нажмите **Отменить правку** на записи — элемент возвращается к значению «до», запись исчезает; повторный ререндер/HMR НЕ воскрешает отменённую правку.
- [ ] Отмена комментария: **Отменить правку** на записи-комментарии удаляет её из журнала и бейдж.
- [ ] Лимит снапшотов: после >50 структурных операций отмена старых недоступна (ожидаемо, без ошибок).
- [ ] Бейджи: на отредактированных элементах и элементах с комментариями появляются бейджи (`ds:mark`).
- [ ] Replay после reload: перезагрузите страницу предпросмотра — правки стиля/текста/классов/атрибутов применяются заново, бейджи восстанавливаются, тост «Восстановлено правок: N».
- [ ] Персист журнала: перезагрузите окно Extension Development Host (**Developer: Reload Window**) и снова откройте студию на том же маршруте — журнал и правки восстанавливаются.
- [ ] Смена маршрута: журнал привязан к маршруту — правки `/` не появляются на `/login` и наоборот; возврат на маршрут восстанавливает его журнал.
- [ ] HMR/reapply: на Next.js-проекте измените исходник компонента (HMR-ререндер) — текстовые/стилевые правки переустанавливаются на элементе автоматически.

## 6. Инструкция для ИИ

- [ ] Копирование: **Скопировать инструкцию** кладёт Markdown в буфер; есть ограждение `PAGE DATA — START/END` с данными страницы внутри.
- [ ] Комментарий вне fence: добавьте комментарий к элементу через попап выбора — в инструкции он находится ВНЕ блока `PAGE DATA` (раздел пожелания пользователя).
- [ ] До/после: правки перечислены с конкретными значениями before/after и селекторами.
- [ ] Исходник компонента: на Next.js-проекте в dev-режиме React **Копировать исходник** копирует файл компонента; цепочка компонентов и подсказки файлов присутствуют.
- [ ] Сохранение стилей: **Сохранить стили** записывает CSS в проект только при однозначном правиле; при нуле/нескольких совпадениях — понятный отказ, файл не тронут.

## 7. Тосты

- [ ] Кнопка закрытия: крестик на тосте скрывает его сразу.

## 8. Безопасность (spot-checks против preview-хоста)

Выполнять из терминала (Git Bash), `<PORT>` — порт preview-хоста из `src` iframe.

- [ ] Dotfile: `curl -i http://127.0.0.1:<PORT>/project/.env` → **403**, содержимое не утекает.
- [ ] ADS-обход: `curl -i "http://127.0.0.1:<PORT>/project/.env::\$DATA"` → **403** (NTFS alternate data stream).
- [ ] SSRF: `curl -i "http://127.0.0.1:<PORT>/proxy/http://example.com/"` (не-loopback upstream) → **403**.
- [ ] Чужой Host: `curl -i -H "Host: evil.example" http://127.0.0.1:<PORT>/` → **403**.

## 9. Подтверждение известных ограничений (ожидаемое поведение, не баги)

- [ ] Структура после reload: структурные правки (перемещение/удаление/дублирование) НЕ восстанавливаются после перезагрузки страницы; их отмена после reload показывает понятный отказ (снапшоты живут только в памяти runtime).
- [ ] Ёмкость журнала: хранится ≤20 маршрутов (старые вытесняются FIFO), reapply-реестр runtime ≤200 записей — без ошибок при переполнении.
- [ ] CSP сохраняется: на странице с CSP (Next.js с заголовками или fixture `/project/csp.html`) в devtools страницы ответ несёт `Content-Security-Policy` с `'self'` и (для nonce-политик) `'nonce-…'`; runtime работает — hover/выбор в режиме правки.
- [ ] CSP unsafe-inline: fixture `csp.html` — inline-скрипт выполняется (маркер `csp-inline-ok` виден), в адаптированной политике нет nonce (чтобы не сломать unsafe-inline приложения).
- [ ] CSP sandbox-fallback: страница с `sandbox` в CSP — заголовок/meta снят, появляется тост «CSP страницы снят: политика содержит sandbox…» (один раз на маршрут).
- [ ] Component detection: на production-сборке React цепочка компонентов не определяется (ожидаемо).

## 10. Регрессионный дозор (FIX-01..08)

- [ ] Первая страница реагирует на режим: сразу после открытия панели переключите **Редактировать** — hover/выбор работают на первой же странице (resync `ds:set-mode` после handshake).
- [ ] Outline на transform: выберите элемент внутри `transform`-позиционированного контейнера — outline заякорен по границам элемента, а не уезжает к началу viewport (FIX-08).
- [ ] Попап: при скролле/resize/смене элемента попап перепозиционируется корректно, не перекрывает выбранный элемент и не выходит за viewport.
- [ ] Handshake после reload: после перезагрузки предпросмотра режим правки и выбор восстанавливаются без повторного переключения.
