# Разработка

## Требования

- VS Code 1.105 или новее;
- Node.js и npm;
- локальный Next.js-проект для проверки предпросмотра.

## Сборка

```bash
npm install
npm run typecheck
npm run lint
npm run build
```

Внутренний runtime собирается отдельно:

```bash
npm --prefix packages/preview-runtime install
npm --prefix packages/preview-runtime run build
```

## Отладка

Откройте проект плагина в VS Code, нажмите F5 и выполните **Дизайн-студия: Открыть дизайн-студию** в Extension Development Host. Для webview доступен `npm run dev:webview`.

В Extension Development Host откройте папку Next.js-приложения и запустите его командой `npm run dev`. Плагин определяет адрес из `package.json` и проверяет доступные локальные серверы. Если обнаружение не сработало, выберите **Сервер** и введите адрес вручную, например `http://localhost:3000`. Для проверки произвольного маршрута укажите его в адресной строке над предпросмотром. Поддерживаются переходы по ссылкам приложения, адресная строка и история назад/вперёд.

Визуальные изменения хранятся в сессии webview. Кнопка **Правка: вкл./выкл.** включает выбор: обычный элемент выбирается кликом, а интерактивный контрол — Alt+кликом. Кнопка **Скопировать инструкцию** формирует список значений до/после вместе с выбранным DOM-элементом, цепочкой React-компонентов и подсказками файлов. Текстовое пожелание можно скопировать и без выбора элемента. Инспектор **Копировать исходник** копирует содержимое найденного файла компонента (до 300 КБ). CSS-правки можно сохранить в найденный файл стилей; остальные правки применяются к исходникам через агента, которому пользователь вручную передаёт скопированный текст.

Если предпросмотр не подключился, проверьте, что локальный сервер Next.js запущен, а консоль **Design Studio Preview** не содержит ошибок запроса. Для диагностики webview используйте **Developer: Open Webview Developer Tools**.

## Обмен сообщениями

Webview отправляет командам расширения сообщения проекта, сохранения CSS, экспорта инструкции, исходника компонента и выбора языка. Страница предпросмотра общается с runtime по версионированному протоколу из `packages/preview-runtime/src/protocol.ts`.
