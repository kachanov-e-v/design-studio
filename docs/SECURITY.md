# Безопасность

- Расширение принимает для предпросмотра только локальные HTTP/HTTPS серверы.
- Путь проекта ограничивается открытой рабочей папкой.
- Внешние ИИ-чаты не вызываются и не получают данные автоматически.
- Текст инструкции и исходник компонента попадают только в буфер обмена после нажатия пользователем соответствующей кнопки.
- Копируемый исходник ограничен файлами кода проекта и размером 300 КБ.
- Webview использует Content Security Policy и получает доступ только к ресурсам расширения.
