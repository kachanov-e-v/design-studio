## Оставшиеся корневые ограничения

### RC1. Правки живут только в DOM и памяти сессии — ЗАКРЫТО (IMP-A, протокол v9)

- Реализовано: журнал правок персистится хостом в `workspaceState`
  (`designStudio.journal.v1`, ≤20 маршрутов FIFO, sanitize полей); webview
  реплеит журнал через `ds:replay` после `ds:runtime-ready` и после загрузки
  журнала для маршрута; runtime ведёт reapply-реестр (LRU ≤200) и переустанавливает
  уплывшие значения через MutationObserver (debounce 100 мс) после ререндера/HMR.
- Undo доступен для всех видов: структура — снапшот `ds:undo`; style/text/
  classes/attribute — replay значения `before` с `forget: true`; комментарий —
  удаление записи журнала.
- Остаточные ограничения (ожидаемые): структурные операции после reload страницы
  не восстанавливаются (снапшоты живут только в памяти runtime), их undo отвечает
  отказом; replay по селектору пропускает исчезнувшие/неоднозначные элементы;
  ёмкость ≤20 маршрутов / ≤200 reapply-записей / ≤50 снапшотов.

### RC2. CSP страницы снимается полностью

- proxy-html.ts снимает CSP-заголовки и meta, иначе инлайн-runtime не выполнится.
  Это ослабляет защиту пользовательской страницы на время превью.
- План (IMP-B): инжекция runtime внешним скриптом (`/__ds-runtime.js` уже отдаётся
  хостом) с nonce; сохранять исходный CSP, добавляя nonce/источник хоста;
  fallback — текущее снятие с явным предупреждением в UI. Задокументировать
  ограничение cookie jar браузера (изоляция сделана на уровне прокси).

### RC3. Компоненты видны только в React dev mode

- fiber.ts читает `__reactFiber$` — в production-сборках данных нет; остаётся
  SourceHintFinder (эвристика по токенам). Vue/Svelte/angular не поддерживаются.
- План (IMP-C): source-map-based детекция (bundler source maps → файл/строка

## Риски и зависимости

- IMP-A reapply должен быть идемпотентным и не конфликтовать с React:
  применять только к существующим селекторам, пропускать исчезнувшие,
  не трогать элементы вне body. (Реализовано; снапшоты структурного undo
  решено оставить только в памяти runtime — после reload их undo отвечает
  отказом, персист DOM-снапшотов не делается.)
- IMP-B: nonce должен ротироваться на сессию; страницы с `strict-dynamic`
  требуют отдельного теста; fallback обязан быть видимым пользователю.
- IMP-C source maps: читать только локальные maps (loopback/файловая система),
  не ходить во внешнюю сеть — иначе новый SSRF-вектор.
- Любой новый тип сообщения → bump PROTOCOL_VERSION + запись в CHANGELOG (IMP-F).
