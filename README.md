# Design Studio

**Design Studio** — независимое расширение VS Code для визуального редактирования страниц и компонентов веб-проекта. Оно не привязано к KiloCode, OpenCode или другому ИИ-агенту, не использует MCP и не вызывает внешние ИИ-сервисы. Расширение готовит подробный контекст и копирует его в буфер обмена; пользователь передаёт его в любой чат или кодовому агенту.

Интерфейс по умолчанию русский. Переключатель **RU / EN** меняет язык интерфейса и создаваемой инструкции.

## Возможности

- предпросмотр локального dev-сервера, в первую очередь Next.js, внутри панели VS Code;
- работа с маршрутами приложения, навигацией назад/вперёд, перезагрузкой и формами авторизации;
- сегментированный переключатель **Просмотр / Редактировать**: в режиме правки предпросмотр обрамляется акцентной рамкой, наведение подсвечивает элемент, клик выбирает его без активации страницы;
- редактирование текста, классов, атрибутов, CSS-свойств и порядка/наличия элемента в живом DOM;
- инспектор со сворачиваемыми секциями и липкими заголовками, фильтром свойств, box-model в стиле devtools (margin/border/padding по сторонам с пересборкой в CSS-shorthand), цветовыми пикерами с альфа-слайдером (rgba) и живым превью типографики;
- журнал правок с чипами вида (стиль/текст/классы/атрибут/структура/комментарий) и значениями до/после; кнопка отмены у каждой правки (структура — DOM-снапшоты, до 50; остальные виды — возврат значения «до»);
- правки переживают перезагрузку: журнал сохраняется в рабочном пространстве VS Code и автоматически применяется заново после перезагрузки страницы и окна, а также после ререндера React/HMR (стили, текст, классы, атрибуты);
- бейджи на элементах с правками и комментариями, ожидающими переноса в код; восстанавливаются после перезагрузки страницы;
- комментарии к элементам через попап выбора — попадают в инструкцию ИИ вне ограждения недоверенных данных `PAGE DATA`;
- инструкция для ИИ с выбранным элементом, цепочкой React-компонентов, подсказками исходных файлов и перечнем правок;
- копирование исходного файла выбранного компонента в чат как отдельного контекста;
- сохранение CSS-правки прямо в проект, если исходное правило найдено однозначно;
- результаты операций — автоскрываемые тосты вместо постоянной строки статуса; иконки интерфейса — inline SVG;
- демонстрационная страница для знакомства с выбором и редактированием без запуска проекта.

## Быстрый старт

1. Откройте папку Next.js-проекта в VS Code.
2. Запустите dev-сервер, например командой `npm run dev`.
3. Откройте палитру команд (`Ctrl+Shift+P`) и выполните **Дизайн-студия: Открыть дизайн-студию**.
4. Выберите предложенный локальный сервер или нажмите **Сервер** и введите адрес, например `http://localhost:3000`.
5. Чтобы открыть маршрут, введите в адресную строку превью путь `/login` или полный локальный адрес `http://localhost:3000/login` и нажмите Enter.
6. Приложение загружается в режиме **Просмотр**: ссылки, кнопки, формы и SPA-навигация работают штатно. Переключите сегментированный переключатель на **Редактировать** — предпросмотр обрамляется акцентной рамкой, наведение подсвечивает элемент, обычный клик по любому элементу выбирает его, не активируя страницу: ссылки не открываются, кнопки не нажимаются, формы не отправляются.
7. Измените элемент в панели инспектора: секции сворачиваются и разворачиваются, фильтр свойств сужает список контролов, box-model позволяет задать margin/border/padding по сторонам. Правьте текст, классы, атрибуты (по типу элемента: `href`, `placeholder`, `checked`, `disabled` и другие) и CSS-свойства, включая цвет с альфа-слайдером. Правка применяется по Enter или потере фокуса, Escape отменяет ввод. Правки стилей, текста, классов и атрибутов сохраняются в журнале и восстанавливаются после перезагрузки страницы/окна и ререндера React/HMR; структурные изменения (перемещение, удаление, дублирование) живут только в текущей сессии предпросмотра.
8. Введите пожелание в нижнее поле и нажмите **Скопировать инструкцию**. Вставьте скопированный текст в любой ИИ-чат.

Если сервер ещё не запущен, выберите **Демо** в списке проекта. После изменений исходного кода или пересборки расширения перезагрузите Extension Development Host/окно VS Code, чтобы загрузились новые собранные файлы.

## Как переносятся изменения

Выбор, тексты, классы, структура и CSS сначала изменяются только в открытой странице предпросмотра. Они не меняют React/Next.js исходники автоматически. Инструкция фиксирует конкретные изменения и объясняет ИИ-агенту, где и что изменить: это структурированный Markdown с блоками «Задача», недоверенные данные страницы (ограждены маркерами `PAGE DATA — START/END`), «Пожелание пользователя» и «Порядок действий» — подробности в [архитектуре](https://github.com/kachanov-e-v/design-studio/blob/master/docs/ARCHITECTURE.md). Исходник выбранного компонента можно скопировать отдельно через **Копировать исходник** в инспекторе.

Кнопка **Сохранить стили** пытается записать CSS-правку непосредственно в проект. Это работает только когда подходящее CSS-правило удалось определить однозначно; если правило отсутствует или совпадений несколько, используйте сгенерированную инструкцию.

Известные ограничения: структурные операции не восстанавливаются после перезагрузки страницы (их отмена после перезагрузки недоступна); журнал хранит до 20 маршрутов; цепочка React-компонентов определяется только в dev-режиме React; preview-прокси снимает CSP страницы, поэтому используйте только доверенные локальные проекты.

## Разработка расширения

```bash
npm install
npm run typecheck
npm run lint
npm run build
npm test
```

`npm test` запускает vitest: 462 теста в 35 файлах.

Загрузите папку расширения в VS Code и нажмите F5, чтобы открыть Extension Development Host. Подробности настройки, сборки и диагностики см. в [руководстве разработчика](https://github.com/kachanov-e-v/design-studio/blob/master/docs/DEVELOPMENT_GUIDE.md) и [руководстве по проблемам](https://github.com/kachanov-e-v/design-studio/blob/master/docs/TROUBLESHOOTING.md).
